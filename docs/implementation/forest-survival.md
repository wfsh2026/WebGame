# 林地围猎：首版实现说明

记录基准：2026-11-05。以下为已有首版实现事实，不替代固定规则，也不将实例数值扩大为平台预算。后续确认但尚未实现的规则见 [实现限制](limitations.md)；代码入口见 [交接导航](../current-state.md)。

## 已实现范围

以下实现表和参数保留 2026-11-05 的历史基准，不作为后续持续波次版本的当前状态；后续已确认设计见文末，实际代码及部署需另行核实。

| 部分 | 当前实现 |
| --- | --- |
| 账号 | 注册、登录、注销；密码派生保存，会话令牌摘要入库，会话有效期 7 天 |
| 角色 | `forest-survival:character/ranger`；账号初始化时选择一次，初始属性总计 20 点 |
| 房间 | Colyseus `expedition`，1～4 人；同账号不能在同一房间重复入场，成员准备、房主开启、开局锁房 |
| 战斗 | WASD、Shift 冲刺、空格正面格挡；一部心法、自动武器、范围技能和仅修饰武器的节能辅助 |
| 怪物 | 普通、快速、精英，复用索敌、追击、前摇、判定、后摇的基础近战行为 |

## 首版参数与行为

来源是内容包清单、共享模拟及房间/API 实现，不应在新内容中复制另一套算法。

- 两轮，每轮刷怪时限 180 秒，到时停止生成，清空敌人后成功。另有生成总量 180、存活上限 48，可能先达到预算，不保证整个时限内一直生成。
- 首次及轮间休息 15 秒；单轮结算展示至少约 6 秒，保存失败则等待重试。
- 初始生命 250、魔法 110、移速 3.03 米/秒、攻速倍率 1.02；20 点分配见清单，不使用演示页的“灵巧”等展示值计算战斗。
- 魔法每秒恢复 5；心法池容量 30，每秒最多恢复 10，基础满额魔法成本 4；按实际转换比例扣费，缺费跳过、池满不扣费。
- 武器与技能独立计时，共享池先恢复再按武器、技能顺序取能；缺能等待，成功后重计时。武器辅助成本 ×0.8、伤害 ×0.85，不扩散至技能。
- 冲刺约 3 米、持续 0.2 秒、冷却 3 秒，不额外扣资源、不自带无敌；正面格挡约 120°，减伤 70%，停止主动移动与新攻击。精确时序以模拟实现为准。
- 实体之间允许重叠，接触不自动扣血；怪物攻击需经过前摇、区域与方向判定。
- 第一轮之后每人可选一次输出、供能或生命成长，超时未选保留当前构筑。轮间恢复生命、魔法、灵力与能力计时。
- 倒地停止操作，队友过关后轮间恢复；全队倒地则本次失败，仍执行成果与最终结算，不再进入下一轮。
- 断线允许原成员重连 30 秒，输入失联约 0.6 秒停止移动和格挡，自动攻击仍可能继续。主动离场或宽限期结束后，已开局角色置为倒地；等待阶段离场会移除成员并转移房主。
- 当前最终奖励：每完成一轮 30 金币，再加个人总击杀（最多计 100）除以 5 后向下取整；每完成一轮 1 份经营素材。失败也按已完成轮数和有效击杀计算，不能写成所有失败一律零奖励。
- 最后一轮单轮结算后直接进入最终结算，不再经过秘境大厅。

## 后续已确认设计与文档差异

2026-11-12 根据用户提供的“技能设定补充”讨论整理以下已确认设计。本节记录产品决定，本次未核实代码或部署，不以历史会话中的发布报告证明当前运行状态。

- 林地围猎最多 20 人，首次准备后持续推进波次；旧怪保留，提前清空则休息至下一波，没有正常通关终点。
- 个人死亡进入可移动、不能攻击的灵魂状态；任务尚未失败时，复活倒计时结束后可以主动在灵魂当前位置复活。
- 灵魂期间继续累计生存时间并获得波次奖励，不自动等同于持续获得升级经验。
- 全员同时处于灵魂状态立即判定失败，停止战斗推进，冻结成果并进行最终个人结算；玩家各自关闭界面返回大厅。
- 复活时长、波次间隔和刷怪参数属于实例参数，不作为全项目固定要求。

上述持续波次设计与 [核心主循环](../gameplay/core-loop.md)现有的多轮小秘境、轮间返回秘境大厅表述尚待协调；不能将波次直接映射成小秘境轮次，也不能凭本节自行删除公共结算记录要求。成长和有等级物品遵守 [构筑成长规范](../gameplay/build-growth.md)，失败后结算物品的发放边界仍待确认。
