# 核心战斗规则：心法供能与能力连接

## 规则地位与适用范围

本文件统一定义心法、角色资源、技能和辅助之间的核心关系，是这些机制的唯一规则来源。内容共创只能在该结构内配置和组合，不能自行替换资源链路、共享关系和独立计时规则。修改核心关系需要用户明确要求。

本规范与 [核心主循环](core-loop.md) 配合使用，不改变秘境大厅、各轮小秘境及两层结算流程。当前有独立的本地构筑原型和真实联机实现；正式战斗由客户端运行共享供能、独立计时和实际命中。首版参数见 [当前实现](../implementation/forest-survival.md)，连续表现职责见 [客户端同步规则](client-presentation.md)，不能混用原型默认值。

## 概念与术语

| 名称 | 定义 |
| --- | --- |
| 魔力属性 | 增加角色魔法攻击力的基础属性，不是可消耗资源 |
| 精神属性 | 增加角色灵力上限和魔法防御的基础属性，不是可消耗资源 |
| 角色灵力 | 唯一可消耗资源，由角色持有，心法提供基础容量与恢复方式，所有连接能力共享 |
| 技能（实际能力） | 连接在心法上的近战或远程技能效果 |
| 辅助格 | 实际能力提供的装配位置，用于放置辅助技能或辅助物品 |

技能统一为近战技能和远程技能，不再设独立武器类型。近战与远程共用心法能力槽，均可提供所属辅助格。战旗、剑阵、陷阵等原技能归为远程技能，分类不代表必须发射投射物。

采用单一灵力池，不再保存或消耗独立角色魔法值。魔力仍影响魔法攻击，精神影响灵力上限和魔防；基础属性本身不被消耗。

## 固定连接结构

角色、怪物及能力表现遵守 [实体显示与控制](entity-controls.md)。

涉及物品等级、槽位解锁和局内强化时，同时读取 [构筑成长规范](build-growth.md)。升级后的连接仍遵守下述共享供能、辅助归属与独立计时规则。

```text
角色灵力池（心法基础容量＋角色容量加成）
    ↑ 心法按间隔直接恢复，叠加明确的恢复加成
    ├─ 技能槽 → 近战技能 → 所属辅助格
    └─ 技能槽 → 远程技能 → 所属辅助格
```

- 心法决定能连接几个实际能力，能力不能超过它提供的槽位数量。
- 每个技能决定自己提供几个辅助格；未装备实际能力时，不存在可独立生效的所属辅助。
- 辅助只修饰所属能力，不默认影响心法、其他能力或所有分支。
- 连接图表示归属和供能关系，不表示辅助按图上排列依次执行。
- 同一心法下的所有实际能力共享角色同一个灵力池，不为每条分支复制容量和恢复收益。

## 心法决定供能，不调度攻击

心法至少声明：基础容量、恢复间隔、单次灵力恢复量、实际能力槽数量。角色灵力上限为心法基础容量加角色容量加成；未装备心法时容量为0，装备心法后的上限最低为1。

到达恢复时机时直接补充角色灵力，不支付第二种资源，不能超过容量上限。角色基础恢复加成为0；凝神回元每次增加1灵力/秒，按心法基础恢复间隔折算到每次恢复量，并随心法条件恢复一起生效。精神属性不提高恢复速度。

心法不分配轮流攻击机会、不统一控制所有能力的攻击间隔，也不限制“整个池子每次只执行一个能力”。恢复间隔与各能力间隔是独立计时。

## 技能独立计时、按次取能

每个实际能力拥有自己的基础间隔和单次灵力消耗，并独立维护当前计时状态。

```text
实际能力到达自己的执行时机
    ↓
检查执行条件，并向所属心法池申请本次所需灵力
    ↓ 灵力足够且满足条件
扣除本次灵力 → 执行近战或远程技能效果
```

- 灵力不足时不能正常执行本次能力，不允许负灵力或隐式借用其他资源。
- 多个能力可以同一时刻执行，前提是共享池中的资源足够支付各次消耗。
- 同刻取能由负责该实体的客户端统一处理，扣除结果必须一致，不能让多个分支重复使用同一份资源。
- 缺能不等于能力未装备；计时未到、等待供能、已触发是不同状态。
- 实际触发与命中是不同事件。投射物已经生成不等于正式命中，不能用播放动画代替客户端战斗算法的实际命中判定。

## 攻击速度与施法速度的作用

界面将攻击速度显示为近战速度、施法速度显示为远程速度；运行属性保留 `attackSpeed`、`castingSpeed`。近战技能沿用物理攻击收益，远程技能沿用魔法攻击收益，本次分类统一不合并属性或改变数值。

攻击速度影响近战技能的攻击间隔，施法速度影响远程技能的执行间隔，两者按作用对象分别计算：

```text
近战技能实际间隔 = 近战技能基础间隔 / 攻击速度倍率
远程技能实际间隔 = 远程技能基础间隔 / 施法速度倍率
```

不能用攻击速度替代施法速度计算远程技能间隔，也不能用施法速度替代攻击速度计算近战技能间隔。角色初始点数对两项倍率的收益沿用角色规范，不因此新增可分配属性。

两种速度均不默认改变心法恢复间隔、恢复量、容量。不得因同时计算动作速度和攻击间隔而重复获得两次完整的频率增益。

独立冷却、持续伤害频率、投射物速度、引导过程与施法前后摇不自动套用额外速度收益；有这些机制时按统一技能规范补充明确行为。施法速度不能仅被解释为缩短读条而不影响远程技能执行间隔。

## 正式连接、供能与计时策略

以下为统一执行策略：

- 能力到达执行时机后缺能时等待，不空过本次机会、不借用其他资源；满足条件并成功执行后重新计算该能力的间隔。
- 同一模拟时刻先处理心法恢复，再按近战、远程技能顺序检查取能与执行；允许资源足够的多个能力在同刻执行，不是心法轮流分配攻击机会。
- 灵力池已满时跳过恢复，不累计溢出或保留为下一次恢复。
- 恢复量超过剩余容量时，只恢复可容纳的部分。
- 换装或升级重新计算上限，保留当前灵力并截掉超出新上限的部分，不因换装补满，也不重置攻击计时。
- 这些策略由公共模拟统一实现，内容配置和共创机制不得各自替换。具体容量、成本和间隔仍属于内容数值，不因策略正式化而全部固定。

## 心法与消耗品的供能效果

- 归流心法5级使连接能力灵力消耗降低8%，10级起降低15%；与所属辅助消耗倍率相乘，不影响其他心法。
- 聚灵符持续10秒，使能力灵力消耗降低20%，覆盖近战、远程技能、布旗及持续光束后续脉冲。
- 原回蓝露滴改为灵力露滴，直接恢复灵力上限的20%；强化品质沿用1.5倍。既有物品标识保留以兼容背包，不再表示第二种资源。
- 周天诀的交替奖励与灵力战旗直接增加恢复，战旗自身收益预算继续生效。

## 辅助修改效果与成本

辅助可以在允许范围内改变所属能力的效果、消耗或间隔，例如多重投射、过载和节能。最终消耗、间隔和效果由统一算法组合计算，不能仅修改说明文字。

装备或卸下辅助后，所属能力的资源需求应同步变化。

辅助兼容性、叠加算法及二次触发边界由公共规则控制。不得通过共创脚本绕过池子供能、获得无限辅助格或形成无限触发链。

## 资源竞争与构筑取舍

```text
理论平均供给 = 心法单次基础恢复量 / 基础恢复间隔（秒）＋角色每秒恢复加成
某能力满速需求 = 最终单次灵力消耗 / 最终执行间隔（秒）
总满速需求 = 所有已装备能力满速需求之和
```

这些是供需预览，不是保证触发频率：还受恢复离散时机、池容量、单次消耗及执行条件影响。

- 池容量提供瞬间储备，不能提高持续供给。
- 攻速和施法速度分别提高对应能力的取能频率，不能自动提高心法供给。
- 一条分支消耗资源后，其他分支可用资源随之减少。
- 总需求超过供给时，不能维持全部能力满速执行。
- 平均供给足够也可能发生瞬间竞争；能力单次消耗超过容量时，不能仅靠等待触发。
- 灵力耗尽后仍按心法规则恢复；持续输出只受唯一灵力池的供需限制。

玩家界面必须清楚表达这些关系，不用单一“伤害提升”掩盖消耗或频率代价。

## 装配与体验界面

装配界面提供心法、技能及所属辅助的装备和卸下，展示槽位归属、最终消耗与间隔，并提示共享供需关系。辅助与所属能力一同管理，不能在能力移除后继续产生独立效果。

确认装配后返回测试位置，由已装配能力自动运行。测试位置展示池中资源、能力计时、触发次数及等待供能原因；不提供手动攻击、补能或直接修改参数的操作。更换构筑返回装配界面。

这是当前构筑测试的交互约定，不代表正式游戏禁止移动、选目标等操作，也不自动允许正式战斗中随时更换装备。

## 原型与正式规则

原型中的名称、数值和槽位仅用于该体验场景，不自动成为平台统一限制。
