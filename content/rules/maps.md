# 地图内容规范

适用范围：内容包 maps/ 下的地图、碰撞与点位数据。

当前首版 Schema 仅支持受限的正交 Tiled 对象图层，包含玩家出生点、怪物出生点及矩形障碍；战斗背景仍是客户端绘制网格。完整瓦片图层、外部 tileset、装饰与事件加载管线尚未实现，下述格式方向不能被当作已有全部能力。

- 使用 Tiled 编辑、导出 JSON；AI 生成内容同样遵守统一格式。
- 首期采用正交俯视角地图。
- 图层职责统一为地面表现、障碍碰撞、装饰表现、出生点和事件点。
- 具体图层名称、对象类型及属性由地图 Schema 定义，不擅自增加具有运行逻辑的新属性。
- 出生点、可行走区、碰撞和事件位置共用一致坐标系。
- 地图源文件、外部 tileset 和贴图依赖必须完整可解析；处理工具拒绝越界路径。
- 服务器使用导出的碰撞和逻辑数据，不加载 Phaser 场景。

- 新增地图对象类型或运行属性时，另读 ../../packages/content-schema/RULES.md。
- 只修改指定包中的地图及其必要资源，不直接修改服务器寻路或碰撞实现。
