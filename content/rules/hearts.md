# 心法内容规范

等级、槽位和局内强化遵守 [构筑成长规范](../../docs/gameplay/build-growth.md)。

先读 [核心战斗规则](../../docs/gameplay/core-combat.md)。本文件仅约束心法内容配置。

目标存放位置为内容包 `hearts/`，使用独立 `heart` 类型 ID，由清单及能力装配数据按 ID 引用；结构与迁移边界见 [内容包规则](packs.md#独立内容与清单职责)。

- 声明基础灵力容量、恢复间隔、单次恢复量及实际能力槽数量，明确单位和允许范围。
- 心法提供池子和连接位置，不自建攻击轮询器或统一的能力触发频率。
- 心法直接恢复角色唯一灵力池，容量叠加角色精神及天赋加成；不消耗第二种资源或基础属性。
- 槽位数量属于心法能力；不得通过配置额外生成不占槽位的实际能力。
- 不私自改变缺能、同刻竞争、恢复溢出或换装补能政策。
- 示例物品数值不作为正式预算，新的容量、恢复效率和槽位范围需按统一数值规则确定。
- 新增字段读取 [内容格式规范](../../packages/content-schema/RULES.md)，新增机制读取 [扩展接口规范](../../packages/content-sdk/RULES.md)。

当前首包心法已位于 `hearts/` 独立文件，由清单 `equipmentFiles` 引用并经 Schema 校验；心法的统一能力槽可装配近战或远程技能。通用跨秘境内容平台仍未完成。
