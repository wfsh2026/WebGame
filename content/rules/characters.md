# 角色核心属性与共创规范

## 适用范围与权限

本文件是角色核心模板、初始属性预算及收益换算的唯一规则来源。适用于角色创作、角色配置格式、属性计算和属性展示。

核心模板及换算规则不可由创作者修改。仅用户明确要求变更公共属性规则时才可调整；普通角色任务不得覆盖基础战斗值、改变系数或新增独立算法。

本文件确认角色属性，不确定通用怪物、技能预算。首版角色清单和共享属性计算已实现，具体实例与减伤实现见 [当前实现](../../docs/implementation/forest-survival.md)，不扩大为全平台数值预算。

## 三层结构

| 层级 | 内容 | 权限 |
| --- | --- | --- |
| 固定核心模板 | 未分配点数时的战斗基础值和属性换算 | 创作者不可修改 |
| 初始属性分配 | 七项属性合计 20 点 | 创作者在规则内分配 |
| 技能与表现 | 近战技能、远程技能、被动、外观等 | 按对应规范创作 |

20 点是七项属性的总预算，不是每项 20 点。创作者可预先配置分配方案，不代表玩家必须手动加点。核心基础值与每点属性收益保持不变。

## 不可修改的未分配核心表

| 战斗属性 | 核心值 |
| --- | ---: |
| 最大生命值 | 200 |
| 灵力容量加成 | 0（最终上限还需叠加心法基础容量） |
| 物理攻击力 | 20 |
| 魔法攻击力 | 20 |
| 物理防御 | 0 |
| 魔法防御 | 0 |
| 移动速度 | 3 米/秒 |
| 攻击速度倍率 | 1.00 |
| 远程速度倍率（施法速度） | 1.00 |
| 幸运修正 | 0 |

逻辑距离统一使用米，地图显示使用固定比例转换。素材尺寸不能改变移动和技能距离。

物理防御、魔法防御保留为派生战斗属性，不作为可独立分配的点数。

当前生命和当前灵力属于运行状态，与最大值分开保存。角色配置不得自行覆盖当前值的运行规则。

## 初始点数与收益

记力量为 P、魔力为 M、体力为 V、精神为 S、移动点数为 R、攻速点数为 A、幸运为 L。

```text
P + M + V + S + R + A + L = 20
各项均为非负整数
```

| 属性 | 每点收益 | 初始战斗值公式 |
| --- | --- | --- |
| 力量 | +2 物理攻击 | 物攻 = 20 + 2P |
| 魔力 | +2 魔法攻击 | 魔攻 = 20 + 2M |
| 体力 | +10 最大生命、+1 物防 | 最大生命 = 200 + 10V；物防 = V |
| 精神 | +5 灵力上限、+1 魔防 | 角色容量加成 = 5S；魔防 = S |
| 移动点数 | +0.5% 基础移动速度 | 移速 = 3 ×（1 + 0.005R）米/秒 |
| 攻速点数 | 攻击速度、施法速度各 +1% | 两项初始倍率分别为 1 + 0.01A |
| 幸运 | 统一概率修正 | 见幸运规则 |

移动和攻速展示时区分分配点数与最终速度，不能把攻速点数解释成每秒攻击次数。体力和精神不默认增加生命、灵力恢复速度。

## 初始配置范围

| 战斗属性 | 20 点预算下的单项范围 |
| --- | --- |
| 物攻、魔攻 | 各为 20～60 |
| 最大生命 | 200～400 |
| 灵力容量加成 | 0～100 |
| 物防、魔防 | 各为 0～20 |
| 移动速度 | 3～3.3 米/秒 |
| 攻击速度、施法速度倍率 | 各为 1.00～1.20 |

这些是各项独立极值，不能同时达到所有最大值。它们只约束初始角色，不代表装备、局内成长和临时效果之后的全局上限。

## 近战与远程速度

- 攻击速度影响近战技能间隔；施法速度影响远程技能间隔，不将施法速度仅解释为缩短前摇或读条。
- 间隔公式与作用边界统一引用 [核心战斗规则](../../docs/gameplay/core-combat.md#攻击速度与施法速度的作用)，本文件不重复维护公式。
- 初始攻速点数沿用已有收益，同时提供两项初始倍率；两者作用对象不同，后续修饰不能默认互相扩散，不新增第八项初始分配属性。
- 独立冷却、持续伤害频率、投射物、召唤物速度和读条不自动获得额外速度收益。
- 下方示例中的速度倍率表示两项初始倍率相同，不表示攻击速度和施法速度是同一个运行属性。

## 幸运

幸运有效上限为 100，初始七项合计 20 点的分配预算保持不变。全队失败的装备掉落减免及死亡经验惩罚遵守 [死亡与失败惩罚](../../docs/gameplay/failure-penalties.md)；下面的有利事件概率公式不用于计算这些不利事件。

对明确声明受幸运影响的有利概率事件，采用：

```text
幸运强度 = L /（L + 100）
最终概率 = p + p ×（1 - p）× 幸运强度 × 0.5
```

p 使用 0～1 的基础概率。基础概率为 0 或 1 时，该公式不改变结果。

| 幸运点数 | 基础概率 10% 时的最终概率 |
| --- | ---: |
| 0 | 10% |
| 20 | 10.75% |
| 50 | 11.5% |
| 100 | 12.25% |

该表展示公式在不同幸运值下的收益，不表示初始允许分配超过 20 点；50 和 100 仅为公式参考值，不授权后期成长范围。

- 事件必须明确适用对象、归属玩家和是否支持幸运，不无差别影响全部随机事件。
- 不默认影响共享地图生成、怪物目标选择、负面事件或其他玩家的效果。
- 互斥掉落池不能逐项套用概率公式。
- 多人共享事件不默认使用幸运之和或最高幸运。
- 幸运不直接放大最终流通货币，不突破奖励上限。
- 不因本文件定义了幸运，就自动新增暴击、额外掉落或其他尚未实现的机制。

## 角色分配示例

以下仅展示合法的 20 点配置，不代表已实现职业、角色或已验证的平衡模板。

| 方向 | 力量 | 魔力 | 体力 | 精神 | 移动 | 攻速 | 幸运 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 战士 | 8 | 0 | 5 | 2 | 2 | 2 | 1 |
| 法师 | 0 | 8 | 2 | 5 | 2 | 2 | 1 |
| 重装 | 4 | 0 | 10 | 3 | 1 | 1 | 1 |
| 游击 | 5 | 0 | 3 | 2 | 4 | 5 | 1 |

| 方向 | 物攻 / 魔攻 | 最大生命 / 灵力容量加成 | 物防 / 魔防 | 移速（米/秒） | 速度倍率 |
| --- | --- | --- | --- | ---: | ---: |
| 战士 | 36 / 20 | 250 / +10 | 5 / 2 | 3.03 | 1.02 |
| 法师 | 20 / 36 | 220 / +25 | 2 / 5 | 3.03 | 1.02 |
| 重装 | 28 / 20 | 300 / +15 | 10 / 3 | 3.015 | 1.01 |
| 游击 | 30 / 20 | 230 / +10 | 3 / 2 | 3.06 | 1.05 |

相同点数不保证战斗强度相同。技能、被动、范围、射程、控制和资源消耗仍需要统一预算，不能作为免费的额外属性。

## 配置与实现边界

- 角色配置只声明身份、初始七项分配及允许的技能和表现引用，不提供覆盖核心表和换算系数的字段。
- 新角色使用内容包内的 `characters/` 目录，沿用内容 ID 格式，例如 `ruins-survival:character/warrior`。
- 精确字段名与 Schema 由内容格式模块统一实现，不在各个内容包中自行定义协议。
- 所有角色复用同一套权威属性计算，客户端展示与预览不能另写不同公式。
- 角色点数在运行时校验为非负整数且总和恰为 20，不能仅依赖 TypeScript 类型。
- 初始 20 点配置与局内成长、大厅强化、装备、临时增益分别管理，不能在配置中伪装后期加成以突破初始预算。
