# 网络与接口契约规范

战斗事件、运行归属、关键同步及必要校验遵守 [客户端战斗与同步](../../docs/gameplay/client-presentation.md)；协议须能标识场次、实体、事件归属和序号。

- 只声明跨端消息及结构，不引用应用实现、数据库模型或服务器内部对象；仅引入必要校验依赖，通过公开导出访问。
- 所有外部输入进行运行时格式、身份和业务权限校验，TypeScript 类型不能代替校验。
- 消息只传递必要数据，不包含隐藏掉落表、密钥或服务器专用规则。
- 修改契约同步处理发送方和接收方，不只改一端。
- HTTPS/WSS 及当前 8080 HTTP/WS 例外遵守 [部署规则](../../deploy/RULES.md)。
