# 内容扩展接口规范

心法、武器、技能及辅助扩展先读 [核心战斗规则](../../docs/gameplay/core-combat.md)，不得通过扩展接口绕过共享池扣费、能力槽位或独立计时。

- 面向经过审核、随服务器统一部署的玩法代码，不执行创作者上传的任意脚本。
- 只提供受控局内上下文、实体操作和事件能力，不暴露数据库、钱包、密钥和原始服务器内部对象。
- 技能、怪物行为和玩法优先组合已有机制，确有新能力时再扩展公开接口。
- 扩展生命周期包含清理职责：阶段退出、效果结束和房间销毁后释放计时任务与订阅。
- 事件仅报告局内行为，不能直接发永久奖励或修改余额。
- 可依赖 contracts、simulation、content-schema 的公开入口，不反向依赖应用。
- 新机制同时读取 ../simulation/RULES.md 及 ../../apps/room-server/RULES.md；配置变更再读 ../content-schema/RULES.md。
- TypeScript 类型、接口和白名单不构成安全沙箱。
