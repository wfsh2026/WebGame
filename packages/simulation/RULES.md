# 共享战斗逻辑规范

实现供能、计时、消耗与能力触发前读取 [核心战斗规则](../../docs/gameplay/core-combat.md)。连接、共享池取能和计时采用其中的正式策略，内容不能自建互不兼容的资源策略。武器间隔使用攻击速度，法术间隔使用施法速度；未确认的其他原型参数不自动成为正式算法。

- 使用纯 TypeScript 普通数据与函数，不依赖其他本地包、应用或运行环境。
- 不引用 Phaser、React、Colyseus、DOM、网络、文件系统和数据库。
- 不使用 Colyseus Schema 作为模拟模型，网络映射由应用适配层完成。
- 时钟与随机数源通过上下文传入，不自行读取真实时间或全局随机数。
- 优先圆形、矩形碰撞及空间网格查询，不默认引入复杂刚体物理或 ECS。
- 客户端复用公共算法运行战斗，包括供能、计时、碰撞、命中、生命和死亡；服务器不默认重复模拟，不要求完整确定性锁步。
- `presentationOnly` 和 `clientDriven` 属于旧实现模式，不能据此限制新客户端只能表现不能结算；迁移时明确共享实体运行归属，使用稳定事件 ID 避免跨端重复命中或移动。边界见 [客户端战斗与同步](../../docs/gameplay/client-presentation.md)。
- 不包含隐藏奖励配置和服务端密钥，不处理永久资产。
- 通过公开导出提供能力；新增配置格式另读 ../content-schema/RULES.md。

涉及角色属性换算、攻速或幸运时，先读 [角色属性规则](../../content/rules/characters.md)。公式仅在所属规则维护；首版具体怪物数值和减伤实现见 [当前实现](../../docs/implementation/forest-survival.md)，不代表通用预算已确定。
